# UI UX Pro Max - AI Design Intelligence Engine

Use this skill whenever creating, modifying, styling, or reviewing user interfaces, landing pages, dashboards, mobile apps, presentations, or design systems.

## Quick CLI Search Engine
Execute python query:
`python skills/ui-ux-pro-max/scripts/search.py [query]`

Available Domains:
- `product`: Matches product type to UI style & landing page patterns
- `style`: 67 UI styles (Glassmorphism, Bento Grid, Neumorphism, Cyberpunk, Swiss, Minimalist, etc.)
- `color`: Curated palettes with primary, secondary, CTA, background, text
- `typography`: Google Fonts pairings with mood & best-use guidelines
- `landing`: Landing page structure, conversion patterns, and section flow
- `motion`: Animation timing, easing, and micro-interactions
- `chart`: Data visualization guidelines and chart selection
- `icon`: Lucide, Heroicons, Phosphor icon recommendations

## Pre-Delivery UI/UX Checklist (Auditor & Crafter)
1. [ ] No emojis as raw icons (use SVG/Lucide icons)
2. [ ] cursor-pointer on all clickable elements
3. [ ] Responsive breakpoints: 375px (mobile), 768px (tablet), 1024px (laptop), 1440px (desktop)
4. [ ] Minimum contrast ratio 4.5:1 for light mode text
5. [ ] Visible focus states for keyboard navigation
6. [ ] Subtle transitions (150-250ms ease-in-out)
7. [ ] Consistent padding and spacing scale (4px, 8px, 12px, 16px, 24px, 32px)
